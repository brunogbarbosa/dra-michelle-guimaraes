# Dra. Michelle Guimarães

Site editorial baseado no template Premium Vendas V3, com hero cinematográfico, retratos reais, galeria de resultados, comparação interativa, navegação mobile e agendamento pelo WhatsApp.

## Desenvolvimento

Requer Node.js 20.9 ou superior.

```sh
npm ci
npm run dev
```

## Validação

```sh
npm run typecheck
npm run build
```

## Vercel

Importe este repositório na Vercel. O framework é **Next.js**, o diretório raiz é **./**, e os comandos padrão de instalação e build são suficientes. Não há variáveis de ambiente obrigatórias. A URL de produção é usada automaticamente nos metadados quando disponibilizada pela Vercel.

## Conteúdo

Dados e links em `data/site.ts`. O WhatsApp foi obtido no Linktree público vinculado ao perfil profissional em 22/09/2026. Não foram informados endereço ou número de registro profissional; esses campos permanecem vazios. Retratos e resultados foram fornecidos pelo solicitante e otimizados para WebP sem retoques adicionais.

Fontes locais com as respectivas licenças em `public/fonts`. O favicon MG usa vinho profundo, marfim e dourado suave. A imagem de Open Graph fornecida foi otimizada para 1200 × 630 px.
